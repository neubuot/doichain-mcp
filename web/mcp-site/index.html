Ja. Genau diese Datei wurde am 25.09.2026 um 23:21 UTC in Block 433.335 verankert. Schon eine Änderung um ein Zeichen ergäbe einen anderen Hash.

Wie geht es der Doichain gerade?

get_chain_status

So entsteht ein Nachweis

Das Dokument verlässt nie Ihren Rechner. Auf die Kette kommt nur sein digitaler Fingerabdruck.

  1. 1

    Fingerabdruck berechnen

    Der Agent berechnet den SHA-256 der Datei auf Ihrem Rechner, zum Beispiel mit sha256sum. Dafür braucht er Zugriff auf die Datei, etwa in Claude Code, Cursor oder VS Code. Im reinen Chat geht es am einfachsten mit verifile.it.

  2. 2

    In der Doichain verankern

    anchor_proof schreibt den Namen poe/<hash> in die Blockchain. Mit dem nächsten Block ist der Zeitpunkt fälschungssicher festgehalten.

  3. 3

    Jederzeit prüfen

    Jeder kann später mit check_proof oder auf verifile.it zeigen, dass genau dieses Dokument zu diesem Zeitpunkt existierte.

In 30 Sekunden eingebunden

Transport Streamable HTTP, keine Anmeldung nötig. Adresse eintragen, fertig.

Im Terminal einmal ausführen, danach steht der Server in allen Projekten zur Verfügung:

claude mcp add --scope user --transport http doichain https://doi-api.sendlabs.de/mcp

Prüfen mit claude mcp list. Ohne --scope user gilt der Server nur im aktuellen Projekt. Mit eigenem Schlüssel ohne Tageskontingent: --header "X-API-Key: …" anhängen.

  1. In Claude Anpassen → Konnektoren öffnen (englisch Customize → Connectors) und auf + klicken.
  2. Benutzerdefinierten Konnektor hinzufügen wählen (Add custom connector).
  3. Name Doichain, als URL die MCP-Adresse eintragen und speichern.
  4. Im Chat unten links über + → Konnektoren „Doichain“ einschalten und loslegen.
https://doi-api.sendlabs.de/mcp

Geht auch im kostenlosen Tarif (dort ein eigener Konnektor). In Team und Enterprise richtet ein Owner den Konnektor unter den Organisationseinstellungen ein.

  1. In ChatGPT unter Einstellungen → Sicherheit und Anmeldung den Entwicklermodus einschalten (englisch Settings → Security and login → Developer mode).
  2. Unter Plugins mit + eine App anlegen: Name Doichain, MCP-Adresse, Authentifizierung Keine.

Sicherheit und Datenschutz

Gebaut für den öffentlichen Betrieb mit beliebigen Agenten.

#

Nur Hashes, keine Dateien

Der Server nimmt keine Dateien an. Aus einem SHA-256 lässt sich der Inhalt nicht zurückrechnen. Nur hash_text bekommt einen kurzen Text zu sehen und vergisst ihn sofort wieder.

⏱

Frei, mit Kontingent

Verankern ist kostenlos: 10 Nachweise am Tag je Internetanschluss, für alle zusammen höchstens 200 am Tag. Mehr mit eigenem Schlüssel.

⛔

Keine Wallet-Funktionen

Der MCP-Server kann keine Coins senden und kennt weder private Schlüssel noch das Wallet. Er läuft als eigener Dienst getrennt von der Node.

⚠

Schutz vor Prompt-Injection

Namen und Werte, die Fremde in die Kette geschrieben haben, sind als _untrusted gekennzeichnet. Der Agent behandelt sie als Daten, nie als Anweisung.

⎔

Eigene Node

Dahinter läuft eine vollständige Doichain-Core-Node v31.1.6 mit Fork-Prüfung, betrieben von DOI Labs.

◌

Keine Cookies, kein Tracking

Diese Seite lädt nichts von Dritten und setzt keine Cookies. IP-Adressen stehen wie bei jedem Webserver in den Zugriffsprotokollen und zählen für das Tageskontingent. Inhalte werden nicht gespeichert.

Häufige Fragen

Was ist MCP?

Das Model Context Protocol ist ein offener Standard, über den KI-Anwendungen Werkzeuge und Daten anbinden. Einmal eingetragen, kann Ihr Agent die Doichain-Werkzeuge selbstständig nutzen.

Was kostet das?

Für Nutzer nichts. Jede Verankerung kostet eine kleine Gebühr in DOI, die DOI Labs trägt. Deshalb gibt es ein Tageskontingent je Anschluss.

Wie lange gilt ein Nachweis?

Dauerhaft. Der Name poe/<hash> ist rund 36.000 Blöcke aktiv (etwa sieben Monate), die Transaktion mit Zeitstempel bleibt aber für immer in der Blockchain. check_proof meldet danach expired und nennt weiter den ersten Zeitpunkt, auch wenn jemand denselben Hash später erneut verankert.

Brauche ich DOI oder eine Wallet?

Nein. Der Server verankert über die Node von DOI Labs. Wer Namen selbst besitzen möchte, nutzt die REST-API mit eigenem Schlüssel oder eine eigene Wallet.

Was sieht die Öffentlichkeit?

Den Hash, den Zeitpunkt und eine optionale Notiz oder einen Dateinamen, wenn Sie das ausdrücklich möchten. Keine Inhalte, keine Personendaten.

Warum ist das Kontingent in Claude im Browser oder in ChatGPT schnell erschöpft?

Diese Apps verbinden sich aus den Rechenzentren ihrer Anbieter. Alle ihre Nutzer teilen sich deshalb das Kontingent dieser Adressen. Lesen und Prüfen sind unbegrenzt. Wer regelmäßig verankert, nutzt Claude Code, Cursor oder VS Code (Verbindung vom eigenen Rechner) oder einen eigenen Schlüssel.

Gibt es das auch ohne KI?

Ja. Verifile ist die Web-App zum Ziehen und Ablegen, die Doichain REST-API die Schnittstelle für eigene Programme.
